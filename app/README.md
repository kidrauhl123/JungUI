# JungUI app

Next.js + TypeScript component catalog with a shadcn source registry.

See the root [README](../README.md), [contribution workflow](../CONTRIBUTING.md), and [conventions](../CONVENTIONS.md).

```sh
npm ci
npm run dev
```

```sh
npm run registry:build
npm run check
npm run build
npm run test:install
```

Static output: `dist/`. Local preview: `npm run preview` (port 4173).

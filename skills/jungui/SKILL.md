# JungUI

用这个库做界面时遵守。准则一条一条加，不预先写满。

## 文案与注释

- 文案、注释越少越好。
- 不要加 Hero，除非用户明确要求。
- 不要把用户的 prompt 写成前端里的文案或注释。

## 容器分离的三种主流流派

严格控制**只用一种显式边界手段**，切忌边框、色差、阴影多重叠加。

| 设计手段 | 适用场景与视觉风格 | 典型案例 |
| :--- | :--- | :--- |
| **仅边框（Border-only）**<br>内外同底色（纯白或纯深灰） | 高信息密度、极简、工具型软件。<br>页面极其轻盈、通透、克制，无大色块压迫感。 | GitHub、Linear、SaaS 控制台数据卡片 |
| **仅色差（Fill-only）**<br>无边框，靠浅灰/纯白区分 | 消费级应用、卡片流、内容消费类。<br>视觉柔和、现代，由色彩自然过渡形成，视觉负担轻。 | iOS 设置、Notion 页面块、资讯流 |
| **仅阴影（Shadow-only）**<br>无边框，同色靠投影分离 | 模拟物理层级（Elevation）、浮层强调。<br>突出悬浮感与点击感，适用于弹窗、菜单、关键模块。 | Material Design、Stripe 卡片模块 |
